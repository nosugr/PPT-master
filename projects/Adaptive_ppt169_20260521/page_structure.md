| P03 | Problem Statement | **Key Problem:** New modes emerge continuously in industrial processes (e.g., roasting: efficient, healthy, over-decomposition, under-oxidation). **Challenge 1:** Model mismatch (historical data can't represent new modes). **Challenge 2:** Catastrophic forgetting (updating with new data loses old knowledge). |
| P04 | Related Work & Gap | **Three existing approaches:** 1) Multiple Models (e.g., multiple PCA) - high complexity. 2) Global Modeling (e.g., LCDL) - statistical averaging. 3) Online Updating (e.g., ODL) - catastrophic forgetting. **Gap:** No method solves both model mismatch and catastrophic forgetting simultaneously. |
| P05 | Proposed Method - Overview | **Proposed:** Jointly Mode-Matching and Similarity-Preserving Dictionary Learning (JMSDL). **Core Idea:** Update dictionary with new mode data only, but constrain the update to preserve similarity to the old dictionary. **Workflow:** K-SVD (Mode 1) → JMSDL (Mode 2) → JMSDL (Mode 3) → ... → JMSDL (Mode N). |
| P06 | Method Detail - Optimization | **Objective Function:** min ||Xn - DnW||²_F + λ1·tr(I - D_o^T D_n) + λ2||W||₁. **Term 1 (Mode Matching):** Minimize reconstruction error for new mode data Xn. **Term 2 (Similarity Preserving):** Keep new dictionary Dn similar to old dictionary Do via trace of similarity matrix. **Term 3 (Sparsity):** L1 norm on sparse codes W. |
| P07 | Method Detail - Algorithm | **Optimization:** Alternating iteration. **Step 1 (Update Dn):** Fix W, solve via matrix decomposition (B = WW^T, B = MVM^T, Dn = QM^T). **Step 2 (Update W):** Fix Dn, solve via Orthogonal Matching Pursuit (OMP). **Online Monitoring:** Calculate reconstruction error IRE, compare to control limit from KDE. |
| P08 | Exp 1 - Numerical Simulation | **Setup:** 4 modes, 20-dim data, 1000 train/250 test per mode. **Key Result 1:** JMSDL avoids catastrophic forgetting (Fig. 7). MRE for mode 1 remains low after learning modes 2-4. **Key Result 2:** JMSDL achieves best FDR/FAR balance compared to mPCA, DL, LCDL, ODL (Fig. 9). |
| P09 | Exp 2 - CSTH Process | **Setup:** 3 modes (different level/temp/valve settings), 1000 train/250 test per mode. **Key Result:** D1 (mode 1 only) → D2 (modes 1+2) → D3 (all 3 modes). MRE for all modes stays at ~0.001-0.004 after learning (Table II). JMSDL detects all 3 fault types (bias on level, multiplicative on temp, multiplicative on flow) while others fail on at least one. |
| P10 | Exp 3 - Real Roasting Process | **Setup:** 4 modes (efficient, efficient-over-decomposition, efficient-under-oxidation, healthy), 25-dim data, 1000 train/500 test per mode. **Key Result:** D4 has low MRE for all 4 modes (Fig. 15). JMSDL achieves low FAR and high FDR. mPCA fails on some modes, DL fails on mode 4, LCDL has low FDR, ODL has catastrophic forgetting. |
| P11 | Results Summary | **Table:** Comparison of methods across all 3 experiments. **JMSDL:** Low FAR, High FDR, No catastrophic forgetting. **Limitation:** JMSDL is a supervised method (requires mode labels). |
| P12 | Conclusion & Future Work | **Conclusion:** JMSDL solves model mismatch and catastrophic forgetting for multimode process monitoring. **Future Work:** 1) Fine-grained similarity (different weights for different atoms). 2) Unsupervised/semi-supervised mode identification. |
