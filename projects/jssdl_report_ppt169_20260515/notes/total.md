# JSSDL 论文复现汇报 - Speaker Notes

## P01 封面
封面页：JSSDL 工业过程监测论文复现汇报。介绍答辩主题、答辩人和导师信息。JSSDL 通过双字典结构（特性字典 D1 + 共享字典 D2）实现工业过程数据中共性与特性的联合建模，显著优于传统 PCA、RPCA 和单字典学习方法。

## P02 目录
目录页：展示本次汇报的五个章节结构。依次为研究背景与问题定义、基线模型及其不足、JSSDL 模型原理与复现实现、数值模拟实验与结果展示、复现问题与总结。

## P03 章节封面 - 研究背景
章节封面：第一章研究背景与问题定义。工业过程数据同时包含共性（跨样本反复出现的公共结构）和特性（工况切换导致的局部稀疏变化），传统方法难以同时处理两类结构。

## P04 工业数据共性与特性
工业过程数据同时包含共性和特性。共性是跨样本反复出现的公共结构，强相关、低秩可压缩；特性来自工况切换，具有稀疏性。右图 TEP 相关性热力图中，偏红或偏蓝的局部块说明多个变量由同一物理机理驱动，呈现稳定相关结构，对应 JSSDL 中共享字典 D2 的建模目标。

## P05 TEP 数据可视化
TEP 数据集可视化证据。上图标准化热力图中，多数变量呈细碎均匀波动，但少数变量在某些时间段出现连续偏红或偏蓝的条带，说明变化集中在部分维度和部分样本段上，符合特性成分稀疏出现的描述。下图高方差时序中，不同变量的峰值位置和变化强度不完全一致，说明某些变量携带了更明显的局部差异。

## P06 章节封面 - 基线模型
章节封面：第二章基线模型及其不足。介绍 PCA 的全局子空间假设和 RPCA 的低秩-稀疏分解，分析两者在工业过程监测中的局限性，引出 JSSDL 的设计动机。

## P07 PCA 与 RPCA 原理
PCA 使用 T2 和 SPE 统计量，假设正常数据可由单一低维子空间描述。RPCA 通过 X=L+S 分解剔除稀疏扰动，但问题是删除特性而非学习特性。右图展示了 RPCA 清理过程：红点为原始样本，绿点为低秩部分，箭头为清理方向。下方对比表显示 JSSDL 的 FDR 达 89.2%，显著优于 PCA(33.2%)、RPCA(48.7%) 和 DL(58.2%)，同时 FAR 保持在 10.5%。

## P08 基线不足定量证据
基线不足的定量证据。上图展示 PCA 和 RPCA 在主空间和残差空间的投影对比，RPCA 残差更集中但故障与正常仍有重叠。下表为 20 次数值模拟平均监测指标：JSSDL 的 FDR 达 89.2%，显著优于 PCA(33.2%)、RPCA(48.7%) 和 DL(58.2%)，同时 FAR 控制在 10.5%。

## P09 章节封面 - JSSDL 原理
章节封面：第三章 JSSDL 模型原理与复现实现。介绍 JSSDL 的核心思想——用特性字典 D1 和共享字典 D2 分别表达稀疏特性和低秩共性，通过联合重构误差 JRE 实现故障监测。

## P10 JSSDL 核心思想
JSSDL 核心思想：用特性字典 D1 和共享字典 D2 分别表达稀疏特性和低秩共性。D1 通过 L1 稀疏约束保证每个原子仅在少数变量上有非零权重；D2 通过核范数低秩约束保证列模式相似，表达公共结构。左图 D1 热力图中大多数位置接近背景色，只有少量竖向点；右图 D2 热力图中多个列呈现相似条纹模式，说明低秩结构有效。

## P11 优化过程与收敛
交替优化过程：四步交替更新 D1→P→D2→X1/X2。P 通过奇异值软阈值收缩保持低秩，再通过 ||D2-P||² 项牵引 D2 保持低秩结构。上图 P 热力图与 D2 形态接近但承担核范数惩罚角色；下图奇异值随迭代下降，说明优化过程趋于稳定。目标函数非联合凸，因此报告中应称"收敛到局部最优或稳定解"。

## P12 参数敏感性分析
参数敏感性分析。左图展示 τ 对 D2 有效秩的影响：τ 越大，越多奇异值被压到 0，D2 有效秩下降。中间和右图展示 τ 与 D1 稀疏度对 FDR 和 FAR 的共同影响，说明参数选择需在故障敏感性和正常工况容忍度之间折中。主实验选择 τ=0.18、D1 稀疏度=2，倾向于保持 D2 低秩和 D1 高稀疏。

## P13 章节封面 - 实验结果
章节封面：第四章数值模拟实验与结果展示。展示数据生成设计、基线监测曲线和 JSSDL 监测结果的对比。

## P14 数据生成设计
数值模拟数据设计。数据由稀疏特性 y1（每样本仅两维度非零）、低秩共性 y2（由 20x2 观测矩阵生成）和高斯噪声叠加而成。左上特性成分几乎全为背景色，只有少数细竖线；右上共性成分呈现多变量共享的条带；左下为叠加后的训练数据 Y；右下测试集后半段施加偏置故障。

## P15 基线监测结果
PCA 和 RPCA 监测曲线。PCA T2 主空间对偏置故障不敏感，代表性单次 FDR 仅 4.0%；SPE 残差空间能捕获部分故障但仍存在较多漏检。RPCA 的 rT2 和 rSPE 比 PCA 有改善，但故障段仍有大量样本未超过阈值，正常段也存在不少尖峰。说明两种方法均无法有效区分正常特性与故障偏移。

## P16 JSSDL 监测结果
JSSDL vs DL 监测结果对比。DL 使用单字典重构，故障段比 PCA/RPCA 更容易越阈值但正常段尖峰多导致 FAR 偏高。JSSDL 的 JRE 在故障段整体抬升，代表性单次 FDR 达 92.4%。加入 ridge_X1=0.05 后，20 次平均 FDR 从 79.6% 提升到 89.2%，FAR 从 10.9% 降到 10.5%。

## P17 复现问题与改进
复现问题与改进。OMP 求解 X1 时少数样本出现过大系数，导致阈值和异常分数不稳定。尝试 Lasso 替代后 FDR 达 100% 但 D2 秩升至 18，偏离低秩建模目标。最终选择在 OMP 最小二乘步骤中加入 ridge_X1=0.05，FDR 从 79.6% 提升到 89.2%，FAR 从 10.9% 降到 10.5%。下图 X1 系数诊断显示监测阶段存在更宽分布和极端离群点。

## P18 总结与致谢
总结与致谢。三个核心结论：(1) JSSDL 双字典结构优于 PCA/RPCA/DL；(2) ridge_X1 正则提升复现稳定性；(3) 后续可继续优化稀疏编码和测试。感谢导师和评审专家。
