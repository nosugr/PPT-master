# P04_章节概述

本章的逻辑链是：首先介绍多模态过程产生的工业背景，然后分析现有方法的局限性，最后引出JMSDL方法的改进思路。

# P05_工业背景

在现代工业过程中，由于制造策略变化和生产技术更新，工业过程往往呈现多种运行模态。SCADA系统积累了大量的历史数据，但传统的单一模型难以适应新的模态。这就产生了多模态过程监测的需求。

# P06_现有方法局限

现有方法主要分为三类：多模型法为每个模态建立独立模型，但模型数量会随模态膨胀；全局建模法将所有模态统一处理，但统计平均效应会掩盖模态特征；在线更新法虽然能随新数据更新模型，但存在灾难性遗忘问题。

# P07_字典学习基础

字典学习是本文方法的基础。其核心思想是用字典矩阵D对数据X进行稀疏表示。首先通过K-SVD初始化字典，然后用OMP算法求解稀疏编码，最后交替优化字典和稀疏系数直至收敛。目标函数是最小化重建误差，同时约束稀疏度。

# P08_灾难性遗忘

灾难性遗忘是在线字典学习方法面临的核心问题。如图所示，ODL方法在逐步更新字典D1到D4的过程中，对历史模态的重建误差持续增大，这就是灾难性遗忘现象。这也是本文要解决的核心问题。

# P09_Part02分隔

接下来进入第二部分：JMSDL方法原理。这是本文的核心贡献。

# P10_核心思想

JMSDL的核心思想包含两个方面：一是模式匹配，将新模态数据与已有字典进行模式级别的匹配；二是相似性保持，在字典更新时保持对历史模态的重建能力，从而克服灾难性遗忘。两者的联合就是JMSDL方法名称的由来。

# P11_目标函数

JMSDL的目标函数由三项组成：第一项是重建误差项，衡量字典对新模态数据的重建能力；第二项是相似性保持项，通过最小化新旧字典的差异来防止遗忘；第三项是稀疏正则项，约束稀疏编码的L1范数。三项协同工作，实现自适应多模态监测。

# P12_Dn更新推导

Dn的更新通过三步完成：首先构建相似性矩阵B等于D0转置乘以Dn，然后对B进行正交对角化分解得到Q和Λ，最终得到闭式解Dn等于Q乘以M转置。这个闭式解无需迭代，计算高效。λ1越大，新旧字典越相似。

# P13_W更新

固定更新后的Dn，使用OMP正交匹配追踪算法求解稀疏编码W。OMP算法每步选择与残差最相关的原子加入支撑集，通过最小二乘更新系数，迭代T次后收敛。OMP保证了稀疏解的高效求解。

# P14_算法流程

JMSDL的完整算法流程如图所示。首先用K-SVD初始化字典D0，然后对每个新数据块依次执行：更新字典Dn、分解相似性矩阵B、计算正交矩阵Q、求闭式解Dn等于QM转置、归一化字典原子、OMP求解稀疏编码W。迭代处理每个新数据块，实现持续学习。

# P15_在线监测

在线监测使用IRE重建误差指标和KDE核密度估计。IRE衡量字典对当前样本的重建误差，KDE利用训练数据的IRE分布计算控制限Rtr。监测规则是：若IRE大于Rtr，则判定为故障，否则正常运行。

# P16_字典更新可视化

这两张图展示了字典的逐步更新过程。从D1到D4，字典逐步学习新模态，同时通过相似性保持项维持对历史模态的表示能力。热力图显示新旧字典保持了良好的结构相似性。

# P17_Part03分隔

接下来进入第三部分：实验验证。我们将通过数值仿真实验和两个工业过程实验来验证JMSDL方法的有效性。

# P18_数值仿真设置

数值仿真采用四模态数据生成系统，每个模态有不同的混合矩阵。训练集4000样本，测试集1000样本，变量维度10维，噪声水平0.01。测试集中注入了阶跃故障和斜坡故障来验证监测灵敏度。

# P19_参数敏感性

λ1的敏感性分析表明：λ1增大会使新旧字典的相似度ds增大，但λ1过大会降低新模态的学习能力。热力图显示在适中的λ1值下，字典结构保持良好。需要在保持与学习之间取得平衡。

# P20_数据表示实验

数据表示实验对比了DL和JMSDL。DL面临灾难性遗忘，历史模态MRE随更新递增；而JMSDL通过持续学习，对所有历史模态保持低MRE，验证了相似性保持项的有效性。

# P21_数值仿真监测

数值仿真监测结果对比了五种方法。JMSDL的FAR最低、FDR最高，综合监测性能最优。ODL因遗忘问题导致FAR较高，mPCA需要维护多个模型。JMSDL在单一模型框架下实现了最优性能。

# P22_CSTH实验

CSTH连续搅拌釜加热过程实验包含三个模态。实验结果表明JMSDL在三种模态下均保持低MRE，监测FDR达到98.7%，FAR仅1.2%，显著优于对比方法，有效克服了灾难性遗忘。

# P23_焙烧过程实验

锌冶炼焙烧过程是真实工业场景，包含四个工况和25维变量。JMSDL在该过程中持续学习，MRE稳定在低水平，监测FDR达99.1%，FAR仅0.8%。这验证了JMSDL在高维真实工业数据上的实用性和鲁棒性。

# P24_Part04分隔

接下来进入第四部分：讨论与分析。

# P25_超参数选择

超参数选择采用网格搜索策略。字典大小K推荐为变量维度的2到4倍；稀疏度T推荐3到5；λ1通过粗搜索确定范围，细搜索优化参数，交叉验证确认最终值。选择标准是最小化历史模态MRE并最大化新模态学习速度。

# P26_JMSDLvsODL

JMSDL与ODL的核心区别在于相似性保持项。ODL的目标函数没有保持项，字典更新仅关注当前数据，导致灾难性遗忘。JMSDL通过λ1乘以tr(I-D0转置Dn)这一保持项，使新字典与初始字典保持相似，从而实现持续学习。

# P27_其他方法对比

与其他方法的综合对比表明：mPCA需要维护多个模型且不支持在线学习；DL和LCDL在遗忘问题上表现一般；ODL支持在线学习但遗忘严重。JMSDL在所有维度上表现均衡，单一模型、在线学习、无遗忘、高效率，综合性能最优。

# P29_贡献总结

本文有三大贡献：第一，提出了JMSDL方法，联合模式匹配与相似性保持的字典学习框架；第二，通过相似性保持项有效克服了在线更新中的灾难性遗忘问题；第三，构建了单一模型覆盖所有模态的持续学习监测框架，包含IRE指标和KDE控制限。
