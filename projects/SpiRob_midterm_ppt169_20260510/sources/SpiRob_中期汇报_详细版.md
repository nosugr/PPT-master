## 1. 研究背景与动机

### 1.1 传统机器夹爪的局限

传统刚性机器夹爪在面对形状不规则、质地脆弱或尺寸多变的目标物体时，存在明显的适应性不足问题。刚性结构在抓取过程中难以顺应物体表面轮廓，容易造成表面损伤，且对不同形状的物体需要设计专用夹具，通用性差。

### 1.2 仿生设计的启发

自然界中，章鱼腕足、植物卷须、象鼻等结构展示了一种极为高效的柔性抓取能力：无需刚性接触，依靠主动弯曲和包覆即可稳定抓持形态各异的目标。这类结构的共同特征是沿轴向的连续弯曲变形，其截面曲率沿长度方向符合自然界中普遍存在的**对数螺旋规律**。

对数螺旋（Logarithmic Spiral）是自然界中最稳定、最高效的卷曲形态之一。其数学表达式为：

$$r = a \cdot e^{b\theta}$$

其中 $r$ 为极径，$\theta$ 为极角，$a$、$b$ 为形状参数。这种曲线在生长过程中保持自相似性，使生物体在任意尺寸下都具有相同的力学特性和抓取效率。

### 1.3 SpiRob 的研究意义

本项目所研究的 SpiRob（Spiral Robot，螺旋机器人）正是以对数螺旋为核心仿生原型，设计一种能够主动实现卷曲、展开、包覆和抓取的二维柔性机器人。其研究意义在于：

- 验证对数螺旋结构在拉线驱动下的运动可行性
- 建立从单元结构到系统动作的嵌入式控制框架
- 为后续多臂协同抓取系统奠定基础
- 探索仿生柔性机器人在非结构化环境中的应用潜力

## 2. SpiRob 基本原理

### 2.1 机器人本体结构

SpiRob 机器人本体由若干**离散单元串联**组成，各单元通过柔性连接依次相连，整体呈一维串联柔性链状结构。单元的几何设计参考对数螺旋的弧度分布，确保在完全卷曲状态下，机器人整体形态贴近对数螺旋曲线。

每个离散单元采用 3D 打印制造，选用 PLA 材料，具有一定的弯曲弹性。单元之间通过连接孔位串联，并在两侧预留驱动线穿线通道。

### 2.2 拉线驱动原理

SpiRob 通过**拉线（Cable-driven）**方式实现主动驱动。两根驱动线分别穿过机器人本体两侧的走线通道，固定在本体尾端，另一端连接至驱动模块的线轴。

驱动原理如下：

- **一侧拉线收缩**：该侧有效长度减小，使机器人向该侧弯曲或卷曲；
- **另一侧拉线收缩**：产生反向弯曲或使机器人展开；
- **双侧协调控制**：通过差动控制两根拉线的收缩量、方向和速度，可以组合出丰富的机器人姿态；
- **拉线放松**：依赖本体材料弹性回复，使机器人从弯曲状态恢复。

### 2.3 对数螺旋与抓取策略的关系

在仿生抓取中，对数螺旋的卷曲特性使机器人能够在展开状态下接近目标，然后通过渐进收紧实现对目标的包覆与锁紧。这种"从外向内渐进包覆"的抓取方式与章鱼腕足捕食猎物的动作高度吻合，能够自然适应物体形状，无需精确的形状先验。

## 3. 系统总体架构

整个中期系统分为三个主要层次：执行层、驱动层和控制层。

```
┌─────────────────────────────────────────────┐
│                 控制层                        │
│   STM32F407 + FreeRTOS + HAL 库              │
│   动作库 / 阶段控制 / 中断停止机制             │
└──────────────────┬──────────────────────────┘
                   │ PWM 脉冲 + 方向信号 + 使能信号
┌──────────────────▼──────────────────────────┐
│                 驱动层                        │
│   两个 DM422 步进电机驱动器                   │
│   24V 电源供电                               │
└──────────────────┬──────────────────────────┘
                   │ 步进电机轴 → 线轴 → 拉线
┌──────────────────▼──────────────────────────┐
│                 执行层                        │
│   两个步进电机 → 两个线轴 → 两根拉线         │
│   → SpiRob 本体弯曲 / 卷曲 / 伸展 / 包覆     │
└─────────────────────────────────────────────┘
```

**信号流向：** STM32 输出 PWM 脉冲和方向信号 → DM422 驱动器接收并放大 → 步进电机转动 → 线轴收放拉线 → SpiRob 本体形变。

## 4. 硬件系统

### 4.1 机器人本体（SpiRob 本体）

SpiRob 本体由多个黄色 PLA 离散单元依次串联构成，整体呈扁平二维结构。各单元外形为楔形/梯形截面设计，内侧走线通道供拉线穿行。单元数量约为 15～20 个，完全展开时长度约为 [参见硬件文档]。

单元通过机械连接结构串联，在两侧分别穿入驱动线，驱动线在尾端固定，另一端通过外壳前端的导线孔引出，连接到线轴齿轮。

实物照片显示，机器人本体在自然状态（未驱动）下呈直线伸展，在拉线驱动下可实现平面内的卷曲弯折，能够包覆直径不同的圆柱形物体（如水瓶、胶带卷等）以及异形物体（如雨伞手柄等）。

### 4.2 驱动与电路系统

#### 4.2.1 电源

系统采用 **24V 直流电源**供电，为步进电机驱动器提供工作电压。

#### 4.2.2 步进电机驱动器（DM422）

系统配置**两个 DM422 数字步进驱动器**，每个驱动器独立控制一路步进电机。

DM422 主要参数：
- 输入信号电压：5～24V（差分或单端）
- 电机驱动电流：可通过拨码开关设置
- 细分设置：通过拨码开关配置，当前配置为 **1600 脉冲/圈**（即 8 细分）
- 信号端口：PUL（脉冲）、DIR（方向）、ENA（使能）、ALM（报警）

两个驱动器分别固定在主控外壳内部，通过排线连接至 STM32 开发板的对应 GPIO 引脚。

#### 4.2.3 步进电机与线轴

系统配置两个步进电机，每个电机轴上安装一个**线轴**（线轴直径 5 mm），拉线缠绕在线轴上。

线轴参数：
- 线轴直径：**5 mm**
- 每圈理论收线长度：π × 0.5 cm ≈ **1.5708 cm**

#### 4.2.4 主控制器（STM32F407）

- 主控芯片：**STM32F407**
- 开发工具：STM32CubeMX 生成初始化代码
- 驱动库：HAL 库
- 实时操作系统：FreeRTOS

### 4.3 外壳结构设计

外壳采用 3D 打印制造，材料为黑色 PLA，整体为长方体盒状结构。外壳前端面安装两个线轴和导线孔，SpiRob 本体由前端引出；外壳内部容纳两个步进电机、两个 DM422 驱动器和 STM32 控制板；外壳顶部留有 ARM 调试器接口和走线口；侧面安装蓝色移动电源作为辅助供电。

外壳整体尺寸约为 [参见硬件外壳文档（硬件部分·外壳.docx）]。

## 5. 嵌入式控制系统

### 5.1 硬件配置概述

嵌入式控制核心为 **STM32F407** 微控制器，负责以下功能：

- 两路步进电机的脉冲（PWM）输出
- 方向信号（DIR）控制
- 使能信号（ENA）控制
- 基于定时器中断的精确脉冲计数与停止
- 运行 FreeRTOS 实时操作系统，组织多任务动作流程

### 5.2 引脚分配

| 功能 | STM32 引脚 | 说明 |
|------|-----------|------|
| PUL1 | PA0 / TIM2_CH1 | 1 号电机脉冲（PWM 输出） |
| DIR1 | PC2 | 1 号电机方向 |
| ENA1 | PC3 | 1 号电机使能 |
| PUL2 | PE9 / TIM1_CH1 | 2 号电机脉冲（PWM 输出） |
| DIR2 | PG0 | 2 号电机方向 |
| ENA2 | PG1 | 2 号电机使能 |

1 号电机使用 **TIM2_CH1** 输出 PWM 脉冲，2 号电机使用 **TIM1_CH1** 输出 PWM 脉冲，两路定时器相互独立，互不干扰。

### 5.3 PWM 控制原理

步进驱动器通过 PUL 引脚接收脉冲信号，**每收到一个有效脉冲，电机前进一步**。

- **PWM 频率** → 决定电机转速（脉冲越密，速度越快）
- **PWM 脉冲总数** → 决定电机转动角度或线轴收线长度

当前配置：
```
MOTOR1_PULSE_PER_REV = 1600  // 1 号电机：1600 脉冲/圈
MOTOR2_PULSE_PER_REV = 1600  // 2 号电机：1600 脉冲/圈
```

两个定时器均配置为 **1 MHz 计数频率**，通过修改自动重装值（ARR）调整 PWM 频率：

```c
arr = MOTOR_TIMER_FREQ / freq_hz - 1U;
```

例如，目标频率设为 3200 Hz 时，电机每秒接收约 3200 个脉冲，每秒转动 2 圈，线轴每秒收线约 3.14 cm。

### 5.4 拉线长度换算

系统以"厘米"为抓取参数的基本单位，内部通过以下公式完成拉线长度到脉冲数的换算：

**线轴每圈收线长度：**

$$L_{圈} = \pi \times d_{轴} = \pi \times 0.5 \text{ cm} \approx 1.5708 \text{ cm}$$

**拉线长度换算为脉冲数：**

$$N_{steps} = \frac{cable\_cm}{L_{圈}} \times MOTOR\_PULSE\_PER\_REV$$

代码中使用四舍五入避免浮点截断误差：

```c
steps = (uint32_t)(steps_float + 0.5f);
```

这一设计使得实验调参时直接以厘米为单位描述动作幅度，极大提升了直觉性和可调节性。

### 5.5 软件架构

工程基于 **STM32CubeMX** 生成，采用 **HAL 库 + FreeRTOS** 架构。

主要文件职责如下：

| 文件 | 作用 |
|------|------|
| `Core/Src/main.c` | 系统初始化、时钟配置、定时器中断回调入口 |
| `Core/Src/tim.c` | TIM1、TIM2 PWM 参数配置 |
| `Core/Src/gpio.c` | ENA、DIR 等 GPIO 初始化 |
| `Core/Src/freertos.c` | 电机控制函数、动作库实现、FreeRTOS 任务流程 |
| `Core/Inc/main.h` | 引脚宏定义 |

FreeRTOS 的引入使得后续可以方便地扩展多任务架构，例如将通信任务、传感器读取任务与动作执行任务并行运行。

### 5.6 三层动作库设计

当前嵌入式代码已经初步整理成**三层动作库**结构，从底层硬件操作到高层动作阶段逐层封装。

#### 5.6.1 底层电机接口（Layer 1）

底层函数直接操作 GPIO、定时器和 PWM，完成对单个电机的基础控制。

```c
// 1 号电机
Motor1_Enable();          // 使能电机
Motor1_Disable();         // 关闭使能
Motor1_SetDir(dir);       // 设置方向
Motor1_SetSpeed_Hz(freq); // 设置 PWM 频率（速度）
Motor1_MoveSteps(steps);  // 发出指定脉冲数后停止

// 2 号电机（对称接口）
Motor2_Enable();
Motor2_Disable();
Motor2_SetDir(dir);
Motor2_SetSpeed_Hz(freq);
Motor2_MoveSteps(steps);
```

#### 5.6.2 中层运动接口（Layer 2）

中层接口将"脉冲数"封装为更直观的物理量：

```c
// 角度控制（以度为单位）
Motor1_MoveAngle(angle_deg, dir, freq_hz);
Motor2_MoveAngle(angle_deg, dir, freq_hz);

// 拉线长度控制（以厘米为单位）
Motor1_MoveCableCm(cable_cm, dir, freq_hz);
Motor2_MoveCableCm(cable_cm, dir, freq_hz);
```

方向宏定义：

```c
#define MOTOR_DIR_CW  0U   // 顺时针：收缩拉线
#define MOTOR_DIR_CCW 1U   // 逆时针：放松拉线
```

#### 5.6.3 高层组合动作接口（Layer 3）

高层接口同时控制两个电机，以"阶段"为单位下发动作指令：

```c
// 同时给两路电机下发动作
Motors_MoveCableCmTogether(
    motor1_cable_cm, motor1_dir, motor1_freq_hz,
    motor2_cable_cm, motor2_dir, motor2_freq_hz
);

// 阻塞等待，直到两路电机均停止
Motors_WaitUntilStop();
```

若某个电机在该阶段无需运动，则对应长度传入 `0.0f`，系统自动跳过该路驱动。

这种三层结构的优势在于：上层动作代码只需关注"这个阶段收几厘米线"，无需关注底层定时器和 GPIO 的细节；同时便于将动作参数抽象为数据表，实现表驱动控制。

### 5.7 四阶段仿生抓取动作流程

当前系统实现了参考论文中的 **Packing → Reaching → Wrapping → Grasping** 四阶段抓取控制流程，能够复现仿生抓取的完整过程。

#### 阶段参数表

| 阶段 | 阶段名称 | 1 号电机 | 2 号电机 | 行为说明 |
|------|---------|---------|---------|---------|
| 阶段 1 | Packing（预卷曲） | 顺时针收缩 2.9 cm | 不动 | 1 号线收紧，本体预先卷曲，为接近目标做准备 |
| 阶段 2 | Reaching（伸展接近） | 不动 | 顺时针收缩 2.5 cm | 2 号线收紧，本体根部弯曲/伸展，朝目标靠近 |
| 阶段 3 | Wrapping（包覆） | 逆时针放松 6.0 cm | 不动 | 1 号线快速放松，尾部展开并沿目标表面包覆 |
| 阶段 4 | Grasping（抓取收紧） | 不动 | 顺时针收缩 4.1 cm | 2 号线进一步收紧，完成最终抓取锁定 |

#### 代码实现

```c
// 阶段 1：Packing（预卷曲）
Motors_MoveCableCmTogether(
    2.9f, MOTOR_DIR_CW, MOTOR_STAGE_SPEED_HZ,
    0.0f, MOTOR_DIR_CW, MOTOR_STAGE_SPEED_HZ);
Motors_WaitUntilStop();

// 阶段 2：Reaching（伸展接近）
Motors_MoveCableCmTogether(
    0.0f, MOTOR_DIR_CW, MOTOR_STAGE_SPEED_HZ,
    2.5f, MOTOR_DIR_CW, MOTOR_STAGE_SPEED_HZ);
Motors_WaitUntilStop();

// 阶段 3：Wrapping（包覆）
Motors_MoveCableCmTogether(
    6.0f, MOTOR_DIR_CCW, MOTOR_STAGE_SPEED_QUICK_HZ,
    0.0f, MOTOR_DIR_CW,  MOTOR_STAGE_SPEED_HZ);
Motors_WaitUntilStop();

// 阶段 4：Grasping（抓取收紧）
Motors_MoveCableCmTogether(
    0.0f, MOTOR_DIR_CW, MOTOR_STAGE_SPEED_HZ,
    4.1f, MOTOR_DIR_CW, MOTOR_STAGE_SPEED_HZ);
Motors_WaitUntilStop();
```

注意在阶段 3 中，1 号电机使用较高速（`MOTOR_STAGE_SPEED_QUICK_HZ`）快速放线，模拟章鱼腕足快速展开包覆猎物的动作特征。

### 5.8 定时器中断停止机制

系统采用**定时器更新中断计数**的方式实现精确的脉冲数控制：

1. 调用运动函数时，先设置目标脉冲数：`motor_target_pulses = steps`
2. 启动 PWM 输出和对应定时器的更新中断
3. 每次定时器更新中断触发时，计数变量自增：`motor_pulse_count++`
4. 当计数达到目标值时，自动停止 PWM 输出：`HAL_TIM_PWM_Stop(...)`

1 号电机由 **TIM2** 回调计数停止，2 号电机由 **TIM1** 回调计数停止，两路电机**独立计数、独立停止**，互不影响。这一机制保证了在 `Motors_MoveCableCmTogether` 调用中，两路电机可以并发执行不同长度的运动，各自在完成目标脉冲数后自行停止，无需 CPU 轮询等待。

## 6. 中期实验结果

### 6.1 基础运动验证

通过调试验证了以下基础能力：

- 两路步进电机独立使能、方向切换、速度控制
- 基于 PWM 脉冲计数的精确运动停止
- 拉线长度到脉冲数的换算正确性
- 双电机同步阶段动作的协调性

### 6.2 四阶段抓取流程验证

在当前固定参数下（见 5.7 节阶段参数表），系统成功在实验台上复现了四阶段仿生抓取流程：

- **Packing** 阶段：机器人本体从自然伸展状态进入预卷曲姿态，为后续接近目标做准备
- **Reaching** 阶段：机器人根部发生弯曲，整体向目标物体方向靠近
- **Wrapping** 阶段：机器人尾部快速展开，沿目标物体表面实现包覆
- **Grasping** 阶段：收紧拉线，完成最终抓取

### 6.3 多目标抓取适应性演示

通过调整动作参数，初步验证了对不同形状物体的包覆能力：

**平面抓取（图 6-1）：** 机器人在桌面沿水瓶外壁完成平面螺旋包覆抓取。

**雨伞抓取（图 6-2）：** 机器人对黑色气球（模拟异形物体）实现包覆，验证对非规则柔性目标的适应性。

**适应不同物体结构（图 6-3）：** 机器人成功包覆胶带卷，验证对不同直径圆柱类物体的抓取能力。

## 7. 当前存在的问题

经过中期阶段的实验验证，当前系统存在以下主要问题和不足：

**1. 无回零流程，重复性差**  
当前系统无初始化回零流程，每次实验开始前需要手动将拉线复位至初始状态，导致每次实验的起始状态不完全一致，影响动作的可重复性和参数一致性。

**2. 速度控制为固定频率，无加减速曲线**  
步进电机以固定 PWM 频率驱动，启动和停止时存在惯性冲击，可能导致步进失步或本体抖动，影响包覆动作的平滑性。

**3. 开环控制，缺乏反馈**  
当前控制为开环拉线长度控制，无拉线张力传感器、无接触检测、无视觉引导，无法根据实际物体形状或接触状态自适应调整动作参数。

**4. 动作参数固定，适应性有限**  
四阶段动作参数（收线长度、速度）目前为经验调试的固定值，不同物体、不同位姿下抓取效果存在差异，尚未实现针对不同目标的自动参数适配。

## 8. 后期规划

### 8.1 总体目标

后期项目将在现有单个 SpiRob 基础上，进一步搭建**三爪手持式人机协同柔性机器夹爪系统**，简称"三 SpiRob 系统"。

最终系统组成：
- **执行层**：三个二维 SpiRob 机器人，安装在底座圆盘前端，形成三爪结构
- **操作层**：操作者握住底座圆盘后方手柄，将夹爪整体移近目标
- **感知层**：笔记本电脑通过 USB 摄像头进行视觉识别，判断目标物体类型及位置
- **交互层**：语音识别系统接收用户指令，指定目标物体
- **控制层**：STM32 作为下位机，控制六路步进电机驱动三个 SpiRob 完成协同抓取动作

### 8.2 从中期到最终形态的过渡路径

```
中期：单个 SpiRob 动作验证（2 电机 / 2 拉线）
    ↓
过渡一：扩展为三个 SpiRob，形成三爪夹爪结构
    ↓
过渡二：由两电机控制扩展为六电机控制
    ↓
过渡三：由固定动作流程扩展为多目标动作库
    ↓
过渡四：加入笔记本视觉识别，区分苹果、香蕉等目标
    ↓
过渡五：加入语音输入，实现指定目标抓取
    ↓
最终：语音 + 视觉 + 手持操作 + 柔性抓取的完整系统
```

### 8.3 最终系统功能规划

**① 手持式夹爪结构**  
三个 SpiRob 安装在底座圆盘前端，操作者握住后方手柄，缓慢将夹爪移近目标物体，由人完成大范围空间移动。

**② 视觉识别功能**  
笔记本通过 USB 摄像头实时识别目标物体（苹果、香蕉等），判断目标是否进入夹爪工作范围，并将识别结果发送至控制系统。

**③ 语音指令输入**  
用户通过语音输入"抓苹果""抓香蕉""缠绕门把手""释放""复位""停止"等指令，系统识别后进入对应目标的抓取模式。

**④ 目标匹配判断**  
系统不是识别到物体就立刻抓取，而是先匹配语音目标与视觉目标的一致性：语音说"抓苹果"，只有苹果进入工作范围时才执行抓取动作；香蕉进入视野范围不会触发误抓。

**⑤ 多目标差异化抓取策略**  
不同物体采用不同的抓取动作库：
- **苹果**：三爪同步包覆式抓取
- **香蕉**：轻夹 + 托举式抓取（避免压坏）
- **门把手**：主臂缠绕 + 辅助臂压紧固定

**⑥ 高摩擦材料辅助**  
在 SpiRob 内侧接触面分段粘贴高摩擦材料，提升抓取稳定性，减少滑脱概率。

### 8.4 后期实施阶段安排

| 阶段 | 任务内容 | 关键里程碑 |
|------|---------|-----------|
| 第一阶段 | 三爪结构搭建：完成三个 SpiRob 在底座圆盘上的安装，设计后方手柄 | 系统具备手持操作条件 |
| 第二阶段 | 三爪动作扩展：将单 SpiRob 动作流程扩展为三路协同，完成打开、复位、抓取、释放、缠绕基础动作 | 三爪能够协同动作 |
| 第三阶段 | 视觉识别加入：接入 USB 摄像头，实现苹果、香蕉目标识别及工作范围判断 | 视觉识别可靠运行 |
| 第四阶段 | 语音与视觉联动：加入语音指令，实现"说抓苹果就只抓苹果" | 指令-目标匹配准确 |
| 第五阶段 | 综合调试与展示：完成苹果、香蕉、门把手三类典型任务演示 | 三类任务抓取成功 |

## 9. 总结

### 9.1 中期成果总结

本阶段围绕 SpiRob 仿生对数螺旋软体机器人，完成了从硬件搭建到嵌入式控制框架建立的全过程验证，主要成果如下：

- **硬件层面**：完成了 SpiRob 本体、驱动外壳、步进电机、DM422 驱动器、STM32 控制板的集成，形成完整的二维 SpiRob 单臂驱动系统；
- **嵌入式层面**：建立了三层动作库控制框架，实现了 PWM 精确脉冲控制、拉线长度换算、双电机同步控制及定时器中断精确停止；
- **动作层面**：完整复现了参考论文的 Packing → Reaching → Wrapping → Grasping 四阶段仿生抓取流程，并验证了对水瓶、胶带卷、气球等不同形状目标的包覆抓取能力；
- **架构层面**：引入 FreeRTOS，为后续多任务扩展奠定了基础。

### 9.2 关键创新点

1. **拉线长度为参数的抓取控制**：以厘米为单位描述抓取动作，提升了实验可调性和直觉性
2. **三层动作库分层设计**：底层操作与高层逻辑解耦，便于后续扩展不同目标的抓取策略
3. **双路独立中断停止机制**：实现两电机真正并发运动，而非顺序执行

### 9.3 后期工作展望

后期工作的核心是将中期"单个 SpiRob 拉线驱动与动作流程验证"，发展为"多 SpiRob 协同手持夹爪系统"。最终要展示的不是简单夹爪的开合，而是一个**能够听懂目标、看见目标、选择正确动作策略，并用柔性 SpiRob 完成抓取的人机协同机器人夹爪系统**。
